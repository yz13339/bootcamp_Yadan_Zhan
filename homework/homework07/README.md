# Homework 07: Outliers, Risk, and Assumptions

Run `homework07_outliers-risk-assumptions_submission.ipynb` from top to bottom using the `bootcamp` environment. Its seeded setup cell reproducibly generates `data/raw/stage07_returns.csv` because the starter notebook referenced by the assignment was not available in the repository or Downloads.

Reusable IQR, Z-score, and winsorizing functions are packaged in `src/outliers.py`. The notebook flags outliers in daily returns, compares all-data, IQR-filtered, and winsorized treatments, includes two plots, and documents the assumptions and risks behind each choice.
